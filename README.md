# Superstore Business Analytics

## Project Overview

This project analyzes retail sales and profitability using the Tableau Sample Superstore dataset.

The objective is to identify sales trends, unprofitable products, regional performance, and the impact of discounting on profit.

## Business Question

How can Superstore improve profitability while maintaining sales growth?

## Tools

- Microsoft Excel
- Tableau Public
- SQL
- GitHub

## Project Structure

- `data/raw` — Original dataset
- `data/cleaned` — Cleaned dataset
- `tableau` — Tableau workbook
- `images` — Dashboard screenshots
- `case-study` — Written analysis
- `presentation` — Project presentation
- `sql` — SQL queries
